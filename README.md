## 项目说明

### hw1 — 学生成绩管理系统
支持成绩录入、字典转换、排序等功能。

### hw2 — 考场管理系统
- `1` 查询学生信息（按学号）
- `2` 随机点名
- `3` 生成考场安排表（保存到桌面）
- `4` 生成准考证文件（保存到桌面）
- `5` 退出系统

> 运行前确保桌面存在 `人工智能编程语言学生名单.txt` 数据文件。

### class5 — NumPy & Pandas
课堂练习：NumPy 数组操作 + Pandas 数据处理基础。

### class6 — 数据可视化
